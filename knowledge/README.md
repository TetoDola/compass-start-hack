# UNRISKOMEGA knowledge and presentation materials

This directory preserves the working materials assembled for the Compass START Hack project.

## Contents

- `20260918_UnRiskOmega_EN.pdf`: official challenge presentation.
- `UNRISKOMEGA_Case_Knowledge_Base.docx`: consolidated case knowledge base.
- `create_case_document.py`: generator for the knowledge-base document.
- `parakeet-transcripts/`: plain-text and timestamped transcripts of the three source recordings.
- `pitch-deck/`: demo storyline, run of show, HTML deck and image assets.
- `rendered-v3/`: latest rendered knowledge-base PDF and page images.
- `rendered/` and `rendered-v2/`: earlier retained render iterations.

The transcripts are machine-generated working records. Check wording against the original recordings before treating a passage as an exact quotation.
