# Five-Minute Pitch — Working Run of Show

## First timing pass

| Time | Beat | Purpose |
| --- | --- | --- |
| 0:00–0:35 | The client call | Create urgency and introduce the portfolio manager |
| 0:35–1:05 | Four questions | Define what the manager must answer immediately |
| 1:05–1:35 | Fragmented context | Show why the current workflow fails under pressure |
| 1:35–2:30 | Live portfolio X-ray | Introduce the product and its core information model |
| 2:30–3:10 | Event-to-impact chain | Explain how the product finds the cause of the loss |
| 3:10–3:35 | Client-ready answer | Complete the human story and show the outcome |
| 3:35–3:45 | Demo handoff | “The client is still waiting. Let’s answer the call.” |
| 3:45–4:45 | Live demo | Show the shortest credible path from alert to explanation |
| 4:45–5:00 | Buffer | Protect against demo latency or land one final sentence |

## Reminder for the next iteration

Explore how to use the available timing margin. Candidate uses:

- one additional product capability that strengthens the story;
- one quantified proof point, once real evidence is available;
- a brief explanation of the ideal customer and buying trigger; or
- more breathing room in the live demo.

Do not fill the margin by default. Keep at least 15 seconds of protected buffer until the demo timing is tested live.
